### 自动化与证据要求

- 全部用例由 `cli/test` 下的自动化测试实现，结果经 OpenLogos reporter 写入 `logos/resources/verify/test-results.jsonl`。
- 不需要人参与；不需要额外的环境要求（夹具自建一次性 git 仓库，本仓测试已依赖 git）；无平台限定用例。

- 「与引入前一致」类断言以同一夹具在引入前实现上生成的 golden 比对。
